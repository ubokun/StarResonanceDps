![ホットキー](images/ja/Settings4.png)

キーを押して、ウィジェットの起動やピン留め、計測などを行う機能です。キーは[全体設定](全体設定)の「ホットキー」で決めます。

## 操作の一覧

| 項目 | 既定のキー | すること |
|---|---|---|
| プレイヤー名表示/非表示 | Ctrl+F11 | 全体設定の「プレイヤー名」を切り替えます。「表示」なら「非表示」に、それ以外なら「表示」にします |
| お気に入りを起動/すべてを停止 | Ctrl+F8 | 起動中のウィジェットがあればすべてを停止し、無ければお気に入りのウィジェットを起動します |
| 起動中をピン留め/ピン留めをすべて解除 | Ctrl+F7 | ピン留めのウィジェットがあればすべてを解除し、無ければ起動中のウィジェットをすべてピン留めします |
| ピン留めをクリック透過/クリック透過をすべて解除 | Ctrl+F6 | クリック透過のウィジェットがあればすべてを解除し、無ければピン留めのウィジェットをすべてクリック透過にします |
| 計測 | Ctrl+F10 | 「[集計](集計)」の「計測」と同じです(計測している間は計測を止めます) |
| リセット | Ctrl+F9 | 「[集計](集計)」の「リセット」と同じです |

## キーの決め方

1. 全体設定の「ホットキー」で、変える項目の欄を押します。欄に「キーを入力」が表示されます
2. 割り当てるキーを押します。Ctrl・Alt・Shiftとの組み合わせもできます
3. 「保存」を押すと確定します

- 同じキーを割り当てていた他の項目は、空欄になります
- 他のアプリが使っているキーは割り当てられません。「ホットキーエラー」のウィンドウが表示され、前のキーのままになります
- 「キーを入力」の間に欄の外を押すと、取り消して前のキーに戻ります
- 「キーを入力」の間に押したキーは、Esc・Deleteも割り当てになります。割り当てを空欄にする操作はありません
- 全体設定の「初期化」で、既定のキーに戻せます

## 注意

- ホットキーは、ゲームかこのアプリが前面のときのみ効きます。そのとき押したキーはゲームに送られません。他のアプリが前面のときは、キーはそのアプリにそのまま送られます
- ホットキーを受け取るには、補助プログラムが必要です。アプリの起動時に補助プログラムを起動し、ユーザーアカウント制御の確認が表示されます。「いいえ」を選ぶと「ホットキーエラー」のウィンドウが表示され、その起動の間はホットキーを使えません
- 補助プログラムが動いていない間は、全体設定の「ホットキー」が表示されません。ホットキーを使わないときは、全体設定の「起動設定」で「アプリ起動時にホットキー補助プログラムを起動」をオフにしてください
- 「[ウィジェット](ウィジェット)」の三点のメニューの項目の後ろにも、その操作のキーが表示されます
