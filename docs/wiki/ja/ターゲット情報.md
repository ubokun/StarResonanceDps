![ターゲット情報](images/ja/EntityInfo1.png)

自分のターゲットの敵の、HP・詠唱・狙っているプレイヤーとヘイト・バフとデバフをまとめて見るウィジェットです。

## 開き方

- 「[ウィジェット](ウィジェット)」の「ターゲット情報」のカードで開きます。ウィンドウは1枚のみです
- [エンティティリスト](エンティティリスト)の行を押すか、行を右クリックして「ターゲット情報」を選ぶと、ウィンドウを開いてその敵を表示します。[マップ](マップ)の敵のアイコンを押したときも同じです

## 見方

- タイトル: 「ターゲット情報」です
- 表示する敵: 自分のターゲットです。ターゲットは、自分が最後にスキルを使った相手の敵です。ゲームでターゲットを選んでも変わらず、スキルを使ったときに変わります。相手のいないスキルを使ったときは、前の敵のままです
- エンティティリストやマップから選んだ敵を表示している間は、ヘッダーに「ターゲットに戻る」が表示されます
- まだスキルを使っていない間は、何も表示しません
- 1行目: エンティティリストの行と同じです(得点は表示されません)。詠唱中は、名前の右にスキルの名前、右端に詠唱のゲージが表示されます。HPのバーの長さはウィンドウの幅に合わせて変わります
- 2行目: いま狙っているプレイヤーと、ヘイトの多い順のプレイヤーです。照準マークとゲージの見方はエンティティリストのヘイトの枠と同じです。入りきらないときは折り返します
- その下: 敵に付いているバフを並べ、行を変えてデバフを並べます。枠の上に名前(表示設定の「バフ名」)、アイコンに重ねて、重なっている数(2以上のとき)、アイコンの下に残りの秒が表示されます
- バフとデバフの並び: 優先表示リストでオンのものが先頭(リストの順)で、残りは付いた順です
- ターゲットの敵が周りからいなくなると(倒された・離れた)、ターゲットは外れて何も表示しません。その後は、次にスキルを使った相手がターゲットになります(同じ敵でも)。敵が周りにいる間は、戦闘が終わってもターゲットのままです

## 操作

- ヘッダーの「ターゲットに戻る」を押すと、自分のターゲットを表示します。選んだ敵に自分がスキルを使ったとき、選んだ敵が周りからいなくなったとき(倒された・離れた)も、ターゲットの表示に戻ります
- バフの枠を押すとその敵の[バフリスト](バフリスト)、デバフの枠を押すと[デバフリスト](デバフリスト)を開きます
- 枠を右クリックすると、「バフリスト」「バフカード」「このバフを優先表示」(優先表示中は「このバフの優先表示をやめる」)「このバフを非表示」を選べます(デバフの枠は「デバフリスト」「デバフカード」「このデバフを…」)。優先表示と非表示は、その場で保存されます
- マウスを乗せると、バフとデバフの枠は名前、戦闘状態のアイコンは「交戦中」、ヘイトの枠は「クラス(狙われている)」「クラス(ヘイト値: 数値)」がTIPSで表示されます
- ウィンドウを小さくしたときは、ホイールか右のスクロールバーで動かします

## 設定

ウィンドウ設定とテーマは[ウィジェットの共通設定](ウィジェットの共通設定)にあります。

### 表示設定

- エンティティ名: 名前の欄に表示する内容を書きます。書き方は[エンティティリスト](エンティティリスト)の「エンティティ名」と同じで、値は別々に持ちます(`Lv.{Level} {EntityName}`)
- バフ名: バフとデバフの枠の名前に表示する内容を書きます(`{BuffName}({CasterName})`)

| 項目 | 文字 | 表示される内容 |
|---|---|---|
| バフ名 | `{BuffName}` | バフの名前 |
| 対象者名 | `{TargetName}` | 敵の名前 |
| 付与者プレイヤー名 | `{CasterName}` | バフを付与したプレイヤーの名前。全体設定の「プレイヤー名」で非表示にすると`*****` |
| レベル | `{Level}` | 敵のレベルの数値 |

- HP数値: バリア量加算表示 / バリア量個別表示 から選びます(バリア量加算表示)
- 戦闘状態: 戦闘状態のアイコンを、表示 / 非表示 から選びます(表示)
- 狙われるプレイヤー: 2行目の左端に、いま狙っているプレイヤーを表示するかです(表示)
- ヘイト値: 2行目に表示する人数を、全員を表示 / 上位5人を表示 / 上位4人を表示 / 上位3人を表示 / 上位2人を表示 / ヘイト1位のみ表示 から選びます(全員を表示)
- 同種バフの表示: まとめない / まとめる から選びます。まとめないは、プレイヤーが付与したバフを付与者ごとに別の枠にします(まとめない)
- 付与者プレイヤー名の表示: 表示 / 非表示 / 他者付与のみ から選びます(他者付与のみ)

### 優先表示リスト

先頭に表示するバフとデバフです。スイッチでオン・オフし、行をドラッグで並べ替えます。既定は「重傷」と2つの「回復禁止」で、どれもオンです。枠の右クリックの「このバフを優先表示」で足せます。足した行はオフにして保存すると消えます。

### 非表示リスト

表示しないバフとデバフです。枠の右クリックの「このバフを非表示」で足します。スイッチをオフにして保存すると、一覧から消えて、再び表示されるようになります。

### アイコンカラー

種類のアイコンと、ヘイトの枠のクラスのアイコンの色を選びます。行と既定の色はエンティティリストと同じです。

## 注意

- ゲームでどの敵をターゲットに選んでいるかは取得できないため、自分が最後にスキルを使った相手をターゲットとして表示します
- 選んだ敵は保存しません。アプリを起動し直すと、自分のターゲットを表示します
- バフとデバフは1秒ごとに読み直します
- アプリを起動する前から周りにいた敵や、敵の情報がまだ足りないときは、ウィンドウのタイトルの円が黄になります。その敵に近づき直すと直ります
- ウィンドウの高さは、行の数に合わせて変わります
- 履歴を開いていても、今の敵を表示します
