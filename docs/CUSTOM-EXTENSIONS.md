## GitHubと更新の管理

## 更新の取り込み手順

作業中の変更をコミットしてから実施する。

```powershell
git fetch upstream
git switch main
git merge --ff-only upstream/main
git switch custom/quest-timeline-builds
git merge upstream/main
```

競合を修正し、ビルドと関連機能の確認後に独自版を保存する。共有済みブランチはrebaseやforce pushで書き換えない。GitHubのSync forkはmainに対して使う。機能追加のPRは自分のFork内で作成する。

```powershell
git push origin main
git push origin custom/quest-timeline-builds
```

## ユーザービルド保存の要件修正（2026-11-08）

対象は他プレイヤーの取得済みビルド。手入力メモ機能は要件を満たさず、置き換えが必要。

- 集計のプレイヤー名から、その集計時点のビルドを確認・保存する。
- ユーザー一覧 → 保存ビルド → そのビルドに紐づく集計一覧へ移動できる。
- プレイヤーはサーバーとCharacterIdで識別する。名前は表示用の当時の値を保存する。
- ビルドは取得時点のスナップショットとして保存し、最新情報で過去のビルドを上書きしない。
- 集計との紐づけにはEncounterIdを使用し、実際にその集計に記録があるユーザーのみ対象とする。同じ場所にいるだけでは参加と扱わない。
- 履歴表示中は当該履歴に保存されたプレイヤー情報を使用し、現在のライブ情報と混ぜない。
- 心相・アビリティ・イマジン・スキルタイムラインを保存対象とする。情報の出所と未取得状態を保持する。
- PlayerRosterEntryにはEquipmentData、RootBuffData、SeasonTalentBuffId、LastReplaceableSkillsなどがある。TalentNodeIdsは他プレイヤーには届かないため完全なアビリティ構成は保証できない。
- 観測されたバフや使用スキルから分かる情報と、全構成が確認できた情報を区別する。未取得を未装備・未習得と解釈しない。
- 紐づいた履歴が保存上限で削除された場合は、ビルドを残し、集計は削除済みと表示する。

現状: 要件と既存データ構造を確認。手入力ビルド画面からの置換・相互リンク・履歴時点の保存は未実装。

## 技フィルター・ヘイト比較ゲージ（2026-11-08）

- タイムラインの「技フィルター」で観測した技を名前検索し、技単位で表示を切り替えられる。プロットとイベント表に共通で適用し、DPSグラフと記録データは変えない。
- 既定では集計時間に対して平均10秒に1回以上の技を非表示にする。同一エンティティ・同一技の時刻を数え、複数人の使用や同時刻の複数対象へのダメージで頻度を水増ししない。同じ技を使ういずれかのエンティティが基準以上なら、その技を既定非表示とする。ライブ中は経過時間に応じて判定が更新される。
- 手動指定を自動判定より優先する。「フィルターを保存」で表示・非表示の指定と有効状態をCombatExtensions.jsonへ保存。「既定に戻す」で手動指定を解除する。検索で隠れた候補の選択も保持する。技のキーに対象名やダメージ値を含めない。
- 敵名は各エンティティのAttrIdから表示言語の名前表で引き、リストとトラックで統一する。情報不足なら「未知の敵」とし、空欄にしない。
- 敵行動のアイコンはスキル表示と同じ別名解決を使う。配布データに絵がない技は汎用の技・予告マーカーで区別する。公式の絵がないものを別技の絵で埋めない。
- エンティティリストのヘイトは1人1本の横ゲージを縦に並べ、1位の値を100%として順位・名前・比率を表示する。既存の表示人数設定（最大5人）と狙われている相手の印を維持する。エンティティ情報ウィジェットの従来表示は維持する。

### ヘイト表示の小型化

エンティティ行を元の44px固定へ戻した。ヘイトは1人7px、ゲージ4px高・角丸2pxで、上位5人と現在の対象の計6段を42pxに収める。名前・順位・比率は小型表示、詳細はツールチップで確認できる。64項目の確認に成功し、6段が元の行内に収まることと丸い端の描画を確認した。

### ヘイト比率の分母修正

比率を1位基準から、受信した全プレイヤーの正のヘイト値の合計基準へ変更した。上位5人より下も分母に含み、表示人数を変更しても比率は変えない。整数合計のオーバーフローを避け、小数第1位で切り捨てて丸めによる表示合計の100%超過を防ぐ。ゼロ合計は0%。ゲージの小型・丸型表示は維持。
